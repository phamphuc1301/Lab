# Lab

A collection of small side projects. Each project lives in its own folder and is self-contained.

| Project | Description |
| --- | --- |
| [habit-tracker](habit-tracker/) | Desktop app (Python + CustomTkinter) for tracking daily habits, with a Windows installer. |
| [money-manager](money-manager/) | iOS app (SwiftUI + SwiftData) for tracking spending: scan receipts with on-device OCR, budgets with overspend warnings. |
| [money-manager-flutter](money-manager-flutter/) | Flutter version of money-manager that runs on Windows and Android: receipt OCR (Windows OCR / ML Kit), SQLite, budget alerts. |
